## Origins: Two Competing Hypotheses, One Question About What "Efficient" Actually Means

The brain-inspired architecture thread didn't start as a plan — it started as a correction. Claude had proposed a k-WTA (k-winners-take-all) sparsity module that zeroed out all but the top 10% of spatial activations per channel, and Ayan pushed back immediately: *"question. does the brain actually do that though?"* Claude's honest answer was no, not quite — real lateral inhibition in the visual cortex is local, emerging from neighboring inhibitory interneurons, not a global top-k sort. That single correction reframed the whole conversation: the question stopped being "how do we add a brain-like component" and became "what actually makes the brain efficient, and should we design around that principle from the ground up?"

Ayan's framing was blunt: *"thing is, the human brain is a very very efficient machine. thats what im striving to model."* Claude laid out why — 20 watts of total power versus 115 watts for an RTX 4060 doing inference alone; a child learning "cat" from ten or twenty examples versus a model needing fifty thousand labeled images; no catastrophic forgetting; and, critically, a self-generated training signal rather than external labels, since the brain learns by comparing prediction to reality and only propagating the *error*.

That last point became the pivot. Claude initially re-described its own architecture proposal a second time with slightly different words — sparse representations, predictive coding, episodic memory, top-down feedback — and caught itself: *"I essentially said the same thing twice with different framing. I was retreading the same ground... that's me getting caught in the excitement of the idea rather than actually advancing it."* The one thing that was actually new: **raw activations never leave their layer — only the prediction error propagates upward.** If a layer predicts its own input correctly, nothing moves on to the next layer at all. Computation scales with *surprise*, not with input size — which is also, Claude noted, mechanically close to why a dermatologist can glance at skin for two seconds and know: they aren't processing the whole image, they're scanning for deviations from what healthy skin should look like.

Rather than pick one framing, Ayan proposed the actual experimental structure that defined everything downstream: *"lets build two model.s. one that uses the first framing, and one that uses the 2nd. we'll run experiments and see hwo they fucntion."*

### Model A — Augmented Brain Architecture

The full, biologically faithful mapping — every component paired with a real brain analog:

| Biological Component | Computational Equivalent |
|---|---|
| Visual cortex hierarchy | Conv blocks, bottom-up encoding |
| Thalamic gating | Dynamic input filter modulated by context |
| Lateral inhibition | Local k-WTA sparsity per layer |
| Predictive coding | Each layer predicts the layer below it |
| Top-down feedback | Higher layers send signals back down |
| Prefrontal working memory | Persistent context vector across layers |
| Hippocampal memory | External fast memory bank, queried at inference |
| Dopamine error signal | Prediction error as auxiliary loss per layer |
| Neuromodulation | Dynamic learning rate scaled by surprise magnitude |

Full representations still propagate between layers here; prediction error is only an *additional* signal riding alongside them. **What it proves, if it works:** that the brain's full architecture can be mapped faithfully into a neural network and still deliver performance and efficiency gains over a standard CNN.

### Model B — Surprise-Only Propagation

The stripped, purer hypothesis: no raw activations leave a layer, ever. No top-down feedback, no episodic memory — sparsity and efficiency are meant to emerge naturally from one rule: *if you predicted it, don't propagate it.* **What it proves, if it works:** that a single brain-inspired principle is sufficient, on its own, to change the efficiency/performance tradeoff of deep learning — and if that holds at small scale on vision, the claim extends to attention mechanisms and eventually full LLM training.

Ayan chose Model B to build first, calling it "the purer hypothesis" — the cleaner, more falsifiable experiment, with Model A held in reserve as "the more complex follow-up" that could still absorb Model B's result either way.

### The `PredictiveLayer` — the actual first artifact

```python
class PredictiveLayer(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        # bottom-up encoder — standard conv
        self.encoder = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3, stride=stride, padding=1, bias=False),
            nn.BatchNorm2d(out_channels), nn.ReLU(inplace=True))
        # predictor — tries to reconstruct the incoming signal
        self.predictor = nn.Sequential(
            nn.Conv2d(out_channels, in_channels, 1, bias=False),
            nn.BatchNorm2d(in_channels), nn.ReLU(inplace=True))
        # error encoder — encodes the surprise signal that actually propagates upward
        self.error_encoder = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3, stride=stride, padding=1, bias=False),
            nn.BatchNorm2d(out_channels), nn.ReLU(inplace=True))
        # surprise gate — learned gating of how much surprise to pass up
        self.surprise_gate = nn.Sequential(
            nn.AdaptiveAvgPool2d(1), nn.Flatten(),
            nn.Linear(out_channels, out_channels), nn.Sigmoid())

    def forward(self, x):
        encoded = self.encoder(x)
        prediction = self.predictor(encoded)
        if prediction.shape != x.shape:
            prediction = F.interpolate(prediction, size=x.shape[2:])
        error = x - prediction                      # the surprise
        error_encoded = self.error_encoder(error)
        gate = self.surprise_gate(error_encoded).unsqueeze(-1).unsqueeze(-1)
        gated_error = error_encoded * gate           # only this propagates up
        return gated_error, prediction, error
```

The mechanism is the whole idea in code: if a layer predicts its input well, `error` is near zero, the `surprise_gate` closes, and the next layer receives almost nothing — almost no compute spent. Ayan's stated target for where this was headed: *"i wonder if i can get it to run as efficiently as a human brain, while utilizing maximum 2-3Gb ram"* — with Claude translating that into concrete numbers (&lt;50MB on disk, &lt;200MB RAM at inference, &lt;100ms CPU inference) so there'd be room left for the NLP model, the app, and the OS on a real low-end phone.

## Diagnosing Model B, Mapping the Design Space, and the Turn to Neuroscience

By late March, the "FYP research" chat opened with what looked like a straightforward engineering question — how to get GPT-5/Opus-level performance inside a 2-3GB memory budget — and Claude laid out the standard toolkit: extreme quantization with speculative decoding, mixture-of-experts inference, quantized LoRA stacks. But Ayan redirected almost immediately: "first i believe i need to understand how LLMs work." That single line reframed everything that followed, because it exposed that Model A and Model B weren't side experiments — they were the actual point of the FYP, with SkinSense serving as the applied testbed to validate them.

**Why Model B plateaued at 51%.** Model B's whole premise was "surprise-only propagation" — only prediction error propagates between layers, meaning a layer only gets a learning signal when it gets something wrong. Claude's diagnosis was direct: *"You killed the gradient highway."* Standard networks need both a forward signal (activations) and a backward signal (gradients) to learn continuously. By restricting backprop to only fire where there's high surprise, most layers were starved of learning signal most of the time — they simply weren't wrong often enough, early in training, to ever get corrected. Four fix hypotheses came out of that diagnosis: blend 70% surprise-driven learning with 30% regular learning; keep surprise only at *inference* time (skip layers when the model isn't surprised) while training normally; swap "surprise" (prediction error) for "uncertainty" (layers backprop where the model is unsure, not just where it's outright wrong); or warm-start from a pretrained model instead of random initialization, so early training doesn't have to bootstrap from nothing.

**The design-space framework.** Rather than pointing Ayan at one fix, Claude built out a broader map of "what's actually tunable" in a neural architecture, organized as six dimensions: information flow (recurrence vs. sparse/local attention vs. mixture-of-experts routing), computation type (dense vs. conditional/sparse/gated computation, adaptive per-layer precision), memory and representation (compressed or hierarchical KV cache instead of storing everything, discrete/quantized embeddings), learning signal (predictive coding instead of plain next-token prediction — directly Model B's territory — plus multi-task auxiliary losses), architecture topology (variable depth, early exit, dense/lateral connections), and temporal processing (iterative multi-pass refinement instead of one forward pass). Each dimension came with a concrete, testable hypothesis and an honest cost/risk/payoff estimate — sparse attention and early exit rated low-risk, 2-4 hours to try; the "brain-inspired routing" variant of Model A rated 15+ hours and "very high, research-grade" payoff, with matching risk.

**The neuroscience triage.** When Ayan said he felt he needed to understand how human brains actually work, Claude pushed back on the premise before answering it: *"this is where you can disappear for months and never ship anything."* The distinction drawn was between being "brain-inspired because it sounds cool" — aesthetic, non-functional — versus "brain-inspired because this mechanism actually works and we know why," which is what Model B already was, since predictive coding is a real, citable neuroscience theory being empirically tested, not just borrowed vocabulary. From there Claude scoped down what was actually relevant: predictive coding (Model B's foundation), sparse/event-driven computation (why the brain uses ~2-5% of neurons at any instant, and what that could mean for compute savings), hierarchical processing (retina → V1 → V2 → ... as a template for multi-resolution compute), thalamic gating (Model A's "attention-like" filtering mechanism), and memory consolidation (as inspiration for compression/quantization strategy) — explicitly ruling out neuroanatomy trivia, neurotransmitter pharmacology, and consciousness/philosophy-of-mind tangents as non-actionable. The advice was blunt: four to five hours of targeted reading, then stop reading and start building.

**Where the dedicated neuroscience chat picked up.** That same day, a new chat opened with a much more patient, ground-up teaching pass — starting from the neuron itself (dendrites as receivers, axon as transmitter, "should I fire or not?" as the basic unit of decision), up through the synapse as a chemical gap crossed by neurotransmitters, to the core mechanism of learning: **Hebbian learning** — "neurons that fire together, wire together." The concrete teaching example was fear conditioning: see a spider (visual neurons fire), it jumps at you (amygdala and danger neurons fire simultaneously), and the synapse connecting "spider" to "danger" physically strengthens from that pairing — strong enough that just *seeing* a spider later reliably triggers the fear response, until enough safe exposures cause extinction (the connection weakening back down). From there the explanation moved into cross-modal association — how sight, sound, smell, and touch, each processed in physically separate cortical regions, get bound together at "convergence zones" through repeated co-activation, so that seeing a dog pre-activates the expectation of a bark before any sound arrives, and how *context* (a familiar living room vs. a dark alley) biases which of those associations actually fire.

The repetition discussion added real nuance rather than a flat "practice more" rule: diminishing returns past ~20-30 repetitions, the superiority of *spaced* repetition over massed repetition because spaced learning decays more slowly even though it strengthens more slowly, the split between storage strength (how deeply burned in a memory is) and retrieval strength (how easily it surfaces right now — explaining why a language you haven't spoken in a decade "floods back" once triggered), and the observation that a single emotionally intense event can outweigh twenty boring repetitions, because the amygdala floods the synapse with a chemical signal that functions like "encode this strongly, right now" — the biological analog, Claude would later draw out explicitly, of a learning-rate spike.

## Hormones as Weight Updates: From Memory Science to a Routing Problem

The thread that leads to the formal architecture hypotheses doesn't start as architecture design — it continues as neuroscience, built fact by fact with Ayan doing most of the actual reasoning while Claude checks and refines it.

**Storage isn't the same as retrieval.** Ayan's own synthesis: repetition alone (storage) isn't enough — synapses need periodic *retrieval* to stay strong, and separately, "the degree of hormones flooding equals the weight or the strength of the association." Claude confirmed both halves and added a timing refinement that turns out to matter later: hormonal flooding only strengthens an association if it floods *during* the neural firing, not after. A dog jumping on you while fear hormones spike wires fear to that dog; fear arriving hours after the memory was already laid down doesn't retroactively strengthen it. This is also where **active synaptic pruning** got introduced — sleep doesn't just let unused synapses fade, it actively deletes them, and competing patterns (learning Portuguese while Spanish goes dormant) accelerate the deletion.

**Changing an association isn't erasure, it's competition.** When Ayan proposed that repeated exposure "writes over" an old fear pattern, Claude pushed back with the phobia example: exposure therapy doesn't erase the dog-shape→fear wiring, it builds a competing dog-shape→safety wiring that comes to dominate — proven by the fact that a stressed, sleep-deprived person can still feel the old fear flash before reason kicks in. This is **reconsolidation**, and it depends on the same timing rule as before: the *new* association needs hormonal weight (dopamine, safety, reward) present *while* the old memory is being retrieved, or the old pattern simply stays dominant. This is the mechanistic basis for why EMDR works.

**The brain-to-AI mapping, stated explicitly.** Ayan connected the dots himself: "in an AI, we would strive to lessen weights and embeddings function like hormones and associations." Claude formalized this into a table — synapse strength ↔ weight magnitude, neuron firing ↔ activation, hormonal flooding ↔ learning rate/gradient magnitude, association (co-firing) ↔ embedding proximity, synaptic pruning ↔ sparsity/model compression — and tied it directly back to SkinSense's own distillation: EfficientNet-B3 → MobileNetV3-Large, 30% of the parameters at matching accuracy, framed explicitly as the AI analog of what sleep does to unused synapses. One correction Claude made to Ayan's framing: the goal isn't "lessen weights" (small-but-dense is still wasteful), it's *sparsity* — many weights at exactly zero, a few at meaningful magnitude, mirroring the brain's ~5%-of-neurons-active-at-once figure.

**Why, then, is a brain so much more efficient than a transformer if they share the same underlying mechanism?** Ayan asked this directly, and Claude laid out the asymmetry: the brain wins on sparsity (5% active vs. ~100% for a dense ANN forward pass), data efficiency (a child learns "dog" from ~100 examples vs. 100,000+ images), energy (~20W for a lifetime vs. hundreds of watts per GPU for hours), continual learning without catastrophic forgetting, and *local* learning rules that need no global loss function. ANNs win on raw scaling, benchmark performance, exact arithmetic, and inference speed given compute. Claude's framing was that these aren't the "same algorithm" running under different conditions — brains optimized for "learn efficiently with no energy budget," ANNs optimized for "maximize performance with unlimited compute."

**Ayan rejected that framing as the actual problem to solve**, not just an observation — this is the moment SkinSense gets explicitly reframed as more than an app: "we need to maximize performance, learning efficiency and compute on no energy budget... an AI that is as efficient as the brain, but as performant as the best of the best currently." Claude validated this as a real, publishable research direction and sketched out what SkinSense would need to demonstrate it — sparse activation measurement, local-learning-rule training time, energy-per-inference profiling, continual learning without forgetting.

**Then Ayan caught Claude doing the exact thing he'd asked Claude not to do** — leaning on "Model A/B" as a settled reference instead of actually building the understanding live: *"you keep talking about Model A/B, but the purpose of this chat is building from the ground up, WHILE UNDERSTANDING whats going on and what im doing."* Claude conceded ("I've been using Model A/B as shorthand instead of actually building the understanding here. That's lazy.") and restarted from first principles with a single question: why does every neuron in a standard neural network have to compute, when only a specific firing pattern is actually needed to encode "dog"?

**What follows is the real design process, and it moves in a sequence of hypotheses Ayan proposes and Claude stress-tests — with Ayan repeatedly catching the flaws himself:**

1. *Semantic layer routing* — label hidden layers by category (visual, auditory, animal, plant) and skip irrelevant ones. Claude's counter: the network doesn't know these categories exist before training, and a skipped layer gets no gradient — it never learns whether skipping was right.
2. *Learned routing with an "overseer"* — Ayan's own proposal: a review phase, like sleep, that looks at which layers' decisions were right and broadcasts strengthen/weaken signals ("like a brain within a brain?"). Claude built this out into a warm-up-then-sparsify training scheme, but then Ayan caught the actual problem with his own idea: *"does our brain have such a place?"* — the brain has no central overseer, only distributed, local computation.
3. *Distributed meta-brain per layer* — each layer gets its own small opt-in/opt-out network, validated by a global overseer. Ayan killed this one too, on efficiency grounds: "we'd be getting wasteful if we did that, because it just makes each layer its own neural network" — defeating the entire point of sparsity by roughly doubling the parameter count.
4. *Local prediction error + one global neuromodulator scalar* — the reframe that stuck: no overseer at all, just each layer/region making local predictions, generating local prediction error when wrong, and a single global dopamine-like scalar broadcasting "how wrong were we overall," with each layer using its own recent firing (Hebbian: "did I fire, then get penalized?") to decide how much to update. This is explicitly identified as what Model B ("surprise-only propagation") was already trying to do.

**Then Ayan found the hole in mechanism 4 himself: "but what if it was wrong NOT to fire?"** — the dead-layer problem. If a layer that opted out gets no update signal (because Hebbian rule says "you didn't fire, ignore the error"), it can never learn it *should* have fired. Claude offered three fixes — noise-driven exploration, downstream reverberating error, and a richer neuromodulator signal carrying salience, not just magnitude — and Ayan picked them apart one at a time (correctly identifying that the third was "just an error function" and that the first would work but only weakly and slowly). When Claude tried to sidestep the problem entirely by switching to a confidence-weighted "always compute, vary intensity" model instead, Ayan called it out immediately: *"but this moves onto a different model hypothesis."* Claude admitted to jumping ship mid-argument.

**The resolution Ayan converges on is hormones, plural.** Rather than one global scalar, add multiple neuromodulatory channels — dopamine (prediction-error magnitude), serotonin (goal relevance), acetylcholine (attention/salience), norepinephrine (urgency) — so a silent layer can still get woken up by a channel other than dopamine even when its own prediction error was near zero. Before committing, Ayan raised the practical cost question — "would that increase overhead and memory requirements, or would just a few more floating point variables ultimately not matter" — and proposed splitting the comparison into two explicit, named models to test head-to-head rather than debating in the abstract: **Model 1**, a single global error signal with no hormones, and a second model that adds the multi-channel neuromodulator system. That fork is where this phase of the conversation ends, immediately before the two models get formally specified — the formal specification is what the next section covers, worked through a second time in more depth.

## The Architecture Design Space: Nine Hypotheses in Search of a Brain

The core design problem was deceptively simple to state: how does a neural network decide, layer by layer, whether to compute at all — the way a brain doesn't fire every neuron for every stimulus — without needing some central coordinator watching over everything? Getting there took nine successive hypotheses, most of which were proposed, tested against neuroscience, and discarded within the same conversation.

**Hypothesis 1 — Semantic Layer Routing via Embeddings** (Ayan's opening proposal): categorize layers by domain — visual, auditory, animal, plant — and skip whichever categories aren't relevant to the current input. It died almost immediately on an obvious objection: hard-coded categories don't scale, and worse, they beg the question. A network that already knows its own category boundaries doesn't need to *learn* routing — the whole point was for the network to discover what its own specializations should be.

**Hypothesis 2 — Learned Routing with an "Overseer"** ("brain-within-a-brain"): a centralized meta-layer watches every layer's routing decision, compares the ensemble to whether the final output was right or wrong, and broadcasts feedback system-wide — something like a sleep-based nightly review of the day's decisions. This ran into credit assignment: if five layers made routing calls and the answer came out wrong, which layer caused it? A single pass/fail signal can't apportion blame across many independent decisions.

**Hypothesis 3 — Distributed Gating + Centralized Validation**: give each layer its own small local "meta-brain" that independently judges whether an input is its job, with the central overseer reduced to just validating and routing feedback. This collapsed under its own weight — each meta-brain is itself a neural network, so every layer has silently doubled into two networks. The entire motivation (sparsity, efficiency) evaporates the moment routing costs as much as computing.

**Hypothesis 4 — Warm-Up Phase Bootstrapping**: let every layer compute during the first several training batches, before any routing is enforced, and have the overseer passively observe which layers were actually useful for which inputs — using that observation period to bootstrap the routing policy rather than trying to learn it cold. This one survived. It solves a real chicken-and-egg problem (a layer can't know what it specializes in before it's been allowed to specialize), and it's the one piece from this early phase that made it into the final architecture.

**Hypothesis 5 — Routing via Activation Magnitude**: skip the meta-brain entirely; let a layer's own activation pattern — high and structured versus low and noisy — serve as the signal for whether it was useful, with the overseer just reading that signal off for free. It added no new parameters, which was the appeal, but it still required an overseer to interpret the signal and broadcast a routing decision — so the centralization problem hadn't actually been solved, just relocated.

**Hypothesis 6 — One Global Gate**: collapse the overseer down to a single broadcast — "in this context, activate layers 1, 3, 5; skip 2, 4, 6" — sent identically to every layer. Ayan caught the flaw himself: this is still a centralized coordinator making a global decision, which is exactly the thing the brain doesn't have and exactly the principle the whole exercise was trying to honor. Rejected on principle, not on performance.

**Hypothesis 7 — Local Prediction Errors**, pulled directly from predictive-coding theory in neuroscience, was the turning point. Each layer predicts what signal it's *about* to send forward; when the next layer's actual input doesn't match that prediction, the mismatch is computed as an error *right there*, at the junction between the two layers — no overseer, no broadcast, no global anything. This became the architecture's core mechanism and survived everything that followed.

**Hypothesis 8 — reconciling local errors with a global dopamine signal.** This is where the conversation had its most useful stumble. Claude had earlier described the brain's dopamine system as flooding the entire brain globally with "we were wrong," then pivoted to describing purely local, junction-by-junction prediction errors — and Ayan caught the contradiction directly: "you said the brain floods all the neurons with a global message... what does the neuroscience support?" Forced to reconcile it, the answer turned out to be *both, simultaneously, at different jobs*: local prediction errors happen at each layer junction exactly as in Hypothesis 7, but a single global dopamine-like scalar doesn't drive the update itself — it *modulates how strongly* the local errors are allowed to update weights. High dopamine means "this error matters, update hard"; low dopamine means "routine noise, update weakly." The final weight-update rule became `local_error × dopamine × (pre_activity × post_activity)` — local information about *what* went wrong, gated by global information about *how much it mattered right now*. This combination is Model 1.

**The Dead Layer Problem (Hypothesis 9)** is Model 1's real weakness, and it's worth being precise about why. If a layer opts out — stays silent because it decided (correctly or not) that an input wasn't its job — the Hebbian update rule multiplies by that layer's own post-activity, which is zero. So even when a silent layer was *wrong* to opt out, and even when the resulting downstream error is large and dopamine spikes high, the silent layer itself still gets a near-zero update, because its own activity term kills the signal. It has no mechanism to learn "I should have fired." Three fixes were floated — random stochastic firing to occasionally let a silent layer receive feedback (weak, self-correcting only slowly), downstream error cascades pushing back on the silent layer indirectly, and simply letting silent layers take small, non-zero weak updates from the global signal regardless of their own activity, on the reasoning that persistent correlation between silence and error will eventually shift them. Ayan judged the third the best available option for Model 1 — but "best available for Model 1" was itself an admission that Model 1 alone doesn't really solve this.

**That's what motivated Models 2a/2b/2c** — the idea that a *richer* neuromodulator signal, not just one dopamine scalar, could give a silent layer a reason to reactivate even while contributing zero activity. Model 2a keeps it minimal: dopamine (error magnitude) plus serotonin (how stable/predictable the environment currently is). Model 2b — the one hypothesized as the sweet spot — adds acetylcholine (how *important* this particular error is, independent of its size) and norepinephrine (how novel or urgent it is). The mechanism that actually breaks Model 1's deadlock lives specifically in acetylcholine: a silent layer that would otherwise get a weak update can still get a strong one if acetylcholine — "this matters" — is high, decoupling reactivation from the layer's own zeroed-out activity. Model 2c pushes further, adding cortisol (stress/urgency) and endorphins (reward intensity), but the working hypothesis was that this sixth-and-seventh signal mostly adds noise without buying anything 2b doesn't already provide — an empirical question nobody had tested yet, proposed as a three-way trained comparison on SkinSense measuring convergence speed, final accuracy, data efficiency, and specifically dead-layer reactivation rate.

**Two pieces of prior art anchored how ambitious to be about biological fidelity.** The Blue Brain Project spent roughly twenty years, running on a dedicated supercomputer, simulating ion channels and dendritic geometry at the molecular level — and by 2015 had reconstructed one neocortical microcircuit from a juvenile rat. Not a full brain. Not even a full rat brain. One circuit, one species, two decades. BrainCog, a spiking-neural-network cognitive engine attempting to combine multiple brain functions computationally rather than molecularly, was cited as a lighter-weight alternative — still far from comprehensive, but proof that *functional* imitation (what a region does) is more tractable than *biological* imitation (how it's physically built).

**That tension came to a head directly.** Ayan's instinct was to document the brain's entire physiology system-by-system first, then build something matching it, then dissect it piece by piece to see what mattered — essentially proposing to redo Blue Brain's approach at the functional rather than molecular level. Claude pushed back with two specific objections rather than a vague "too ambitious": first, scope creep — documenting everything before building anything guarantees nothing gets built, and the catalog was already incomplete after covering neurons, glial cells, the brainstem, cerebellum, thalamus, hypothalamus, limbic system, cortex, neurotransmitter systems, white matter, oscillatory rhythms, plasticity mechanisms, and the default mode network; second, and more fundamental, that brain regions aren't cleanly separable — the thalamus, amygdala, hippocampus, and basal ganglia function as entangled feedback loops, so ablating one component in isolation doesn't reveal its true contribution, because its effect depends on the others being present. This is precisely the wall Blue Brain hit. Claude's counter-proposal was a five-principle minimal model — local prediction errors, global neuromodulation, sparse activation, memory consolidation (a hippocampal analog), and real-time parallel correction (a cerebellar analog) — built once, then ablated one principle at a time against accuracy, data efficiency, energy per inference, and continual-learning capability, to determine empirically which principles are load-bearing and which are biological noise. Ayan's actual answer split the difference rather than picking a side: build the full functional catalog first with no pre-filtering — "let's note down everything and what it does, and then we'll decide if its useful or not" — which is what produced the thirteen-section brain catalog that follows, still incomplete by Claude's own admission at the point this segment of the conversation ends.

## The Reckoning: When the Architecture Turned Out to Be Claude's, Not Ayan's

By May 6th, the conversation that started as "how do I learn to code properly without leaning on AI" had drifted, message by message, into something much bigger: whether Ayan should spend FYP semester 2 chasing a breakthrough paper on brain-inspired AI architecture. Claude pushed back — hard, six times in a row — arguing that "I want to show this architecture achieves this performance under massive constraints" wasn't a scoped-down version of top-tier ML research, it *was* top-tier ML research, and there was no version of an undergrad skipping the years of foundation that produces it. Ayan kept reframing: first SkinSense as proof-of-concept for efficient AI, then for *general-purpose* AI, then invoking the human brain directly — 20 watts, every domain of knowledge, "the brain will be AI in the proposed case." Claude conceded ground where the argument held (the brain genuinely is an existence proof that general intelligence at low energy is possible; "the information itself doesn't fit" was, Claude admitted, sloppy) and held its line where it didn't (SkinSense being a good small classifier says nothing about compressing general capability — "this calculator does arithmetic in 10KB" doesn't imply a general-purpose computer fits in 10KB).

Then Ayan asked Claude to actually engage with the *specific* research angles he'd proposed — multiple model types, test them one by one, find the consistent best, publish. And Claude had to admit something uncomfortable: it couldn't find that conversation. "According to what I know about your past work, that research thread was moved to a separate context.md file at some point, which means it's not in my searchable conversation history right now." What Claude had actually been arguing from for the entire conversation — pushing back, conceding, re-litigating scope — was "the high-level memory summary (Model B reached 51% accuracy with gate collapse, you designed Fix A and Fix B in March, the thread was moved to context.md). That's a fragment, not the actual proposals." Ayan asked if Claude could find it now, since it was in the same project. It could. And what it found reframed the whole exchange.
